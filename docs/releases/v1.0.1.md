# PFE v1.0.1

## 日本語

ROCKNIX向けのPFEパッチリリースです。

### ダウンロード

Assets から `pfe-rocknix-v1.0.1-20260527.zip` をダウンロードしてください。

GitHubが自動生成する `Source code.zip` / `Source code.tar.gz` ではなく、上記ZIPを使用してください。ROCKNIX向けZIPには、`/roms/pfe` に置く `pfe/` と、`/roms/ports` に置く `ports/` が含まれています。

### 変更内容

- `02_install_pfe.sh` がRetroArch設定へ `menu_driver = "rgui"` を書き込むようにしました。
- 互換用の `tools/rocknix/rocknix_pfe_service_install.sh` も同じ処理に更新しました。
- RGB30などの小型画面で、RetroArchメニューがXMBではなくRGUIで開くようになります。
- RetroArchスクリーンショット設定の補正は従来通り維持しています。

### ROCKNIXでの導入

1. ZIP内の `pfe/` を `/roms/pfe` に配置
2. ZIP内の `ports/` の中身を `/roms/ports` に配置
3. EmulationStationのPortsから `01_install_pyxel.sh` を実行
4. 続けて `02_install_pfe.sh` を実行
5. PFEへ切り替える場合は `Switch_to_PFE.sh` を実行

既にPFEを導入済みの場合も、新しいZIPで `/roms/pfe` と `/roms/ports` を更新してから `02_install_pfe.sh` を再実行してください。

## English

This is a patch release for PFE on ROCKNIX.

### Download

Download `pfe-rocknix-v1.0.1-20260527.zip` from Assets.

Use this ZIP instead of GitHub's automatically generated `Source code.zip` / `Source code.tar.gz`. The ROCKNIX ZIP contains `pfe/` for `/roms/pfe` and `ports/` for `/roms/ports`.

### Changes

- `02_install_pfe.sh` now writes `menu_driver = "rgui"` to the RetroArch configuration.
- The compatibility script `tools/rocknix/rocknix_pfe_service_install.sh` has the same update.
- On small-screen devices such as the RGB30, the RetroArch menu now opens with RGUI instead of XMB.
- The existing RetroArch screenshot configuration fixes are unchanged.

### Installing on ROCKNIX

1. Copy `pfe/` from the ZIP to `/roms/pfe`
2. Copy the contents of `ports/` from the ZIP to `/roms/ports`
3. Run `01_install_pyxel.sh` from EmulationStation's Ports menu
4. Then run `02_install_pfe.sh`
5. To switch to PFE, run `Switch_to_PFE.sh`

If PFE is already installed, update `/roms/pfe` and `/roms/ports` with the new ZIP contents, then run `02_install_pfe.sh` again.
