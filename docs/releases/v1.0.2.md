# PFE v1.0.2

## 日本語

ROCKNIX向けのPFEパッチリリースです。

### ダウンロード

Assets から `pfe-rocknix-v1.0.2-20260527.zip` をダウンロードしてください。

GitHubが自動生成する `Source code.zip` / `Source code.tar.gz` ではなく、上記ZIPを使用してください。

### 変更内容

- `Switch_to_PFE.sh` 実行後、OS再起動でEmulationStationへ戻ってしまう問題への対策を追加しました。
- `Switch_to_PFE.sh` はsystemdの一時ジョブとして切り替え処理を実行し、EmulationStationが停止しても処理が最後まで継続するようにしました。
- `02_install_pfe.sh` は `/storage/.config/autostart/99-pfe-frontend` を配置し、ROCKNIXがUIサービスを起動する直前に保存済みフロントエンドを再適用します。
- ROCKNIXが `/storage/.config/profile.d/090-ui_service` を起動時に初期化する場合でも、`/storage/.config/pfe/frontend.conf` の選択状態からPFE/ESを復元します。
- `/roms/pfe` がSD2上にある場合に備えて、PFE本体ファイルと `/storage/roms` の準備を待ってから `launcher.sh` を起動します。
- PFE起動前にWaylandソケットを待つようにし、PyxelがEGL初期化に失敗しにくいようにしました。
- 切り替え時は、`pfe.service` がactiveかどうかだけでなく `main.py` が数秒安定して動作していることを確認します。PFEが起動できない場合はEmulationStationへフォールバックします。
- 配布前の検証で使用した古い `pfe-frontend-apply.service` が残っている場合は、`02_install_pfe.sh` の再実行で無効化・削除します。
- 既存のRetroArch `menu_driver = "rgui"` 設定は維持しています。

### 既存環境の更新

既にPFEを導入済みの場合は、新しいZIPで `/roms/pfe` と `/roms/ports` を更新してから、EmulationStationのPortsで次を実行してください。

1. `02_install_pfe.sh`
2. `Switch_to_PFE.sh`

`02_install_pfe.sh` の再実行が必要です。これにより、SD2待機とWayland待機を含む最新の `pfe.service` と、起動時再適用用のautostartスクリプトが登録されます。

## English

This is a patch release for PFE on ROCKNIX.

### Download

Download `pfe-rocknix-v1.0.2-20260527.zip` from Assets.

Use this ZIP instead of GitHub's automatically generated `Source code.zip` / `Source code.tar.gz`.

### Changes

- Added a fix for cases where ROCKNIX returns to EmulationStation after reboot even after running `Switch_to_PFE.sh`.
- `Switch_to_PFE.sh` now runs the switch flow as a transient systemd job so it can continue after EmulationStation stops.
- `02_install_pfe.sh` now installs `/storage/.config/autostart/99-pfe-frontend` to re-apply the saved frontend right before ROCKNIX starts the UI service.
- Even if ROCKNIX resets `/storage/.config/profile.d/090-ui_service` at boot, the selected PFE/ES frontend is restored from `/storage/.config/pfe/frontend.conf`.
- When `/roms/pfe` is on the second SD card, `pfe.service` waits for the PFE files and `/storage/roms` before starting `launcher.sh`.
- PFE now waits for the Wayland socket before startup, reducing Pyxel EGL initialization failures.
- The switch step now checks that `main.py` stays running for a few seconds, not just that `pfe.service` is active. If PFE cannot start, it falls back to EmulationStation.
- If the old pre-release `pfe-frontend-apply.service` remains on a device, re-running `02_install_pfe.sh` disables and removes it.
- The existing RetroArch `menu_driver = "rgui"` setting is unchanged.

### Updating an Existing Install

If PFE is already installed, update `/roms/pfe` and `/roms/ports` with the new ZIP contents, then run these from EmulationStation's Ports menu:

1. `02_install_pfe.sh`
2. `Switch_to_PFE.sh`

Re-running `02_install_pfe.sh` is required because it registers the updated `pfe.service` storage/Wayland waits and the boot-time autostart re-apply script.
