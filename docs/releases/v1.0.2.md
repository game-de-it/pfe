# PFE v1.0.2

## 日本語

ROCKNIX向けPFEの初回推奨リリースです。

### ダウンロード

Assets から `pfe-rocknix-v1.0.2-20260527.zip` をダウンロードしてください。

GitHubが自動生成する `Source code.zip` / `Source code.tar.gz` ではなく、上記ZIPを使用してください。ROCKNIX向けZIPには、`/roms/pfe` に置く `pfe/` と、`/roms/ports` に置く `ports/` が含まれています。

### ROCKNIXでの導入

1. ZIP内の `pfe/` を `/roms/pfe` に配置
2. ZIP内の `ports/` の中身を `/roms/ports` に配置
3. EmulationStationのPortsから `01_install_pyxel.sh` を実行
4. 続けて `02_install_pfe.sh` を実行
5. PFEへ切り替える場合は `Switch_to_PFE.sh` を実行

詳しい手順は、ZIP内の `pfe/docs/ROCKNIX_JP.md` を参照してください。

### 主な内容

- ROCKNIX向けPFE導入スクリプト
- Pyxel 2.9.5対応
- RetroArch / Pyxel / スタンドアロンエミュレータ起動
- PFE / EmulationStation切り替え
- スクリーンショットギャラリー
- 日本語表示、テーマ、BGM、ゲームパッド設定
- お気に入り、最近遊んだゲーム、検索、統計

### 安全策

- `02_install_pfe.sh` はPFE依存関係を確認してからサービス登録します。
- `02_install_pfe.sh` はRetroArchのスクリーンショット設定と `menu_driver = "rgui"` をPFE向けに補正します。
- `/roms/pfe` がSD2上にある場合に備えて、PFE本体ファイルと `/storage/roms` の準備を待ってから起動します。
- PFE起動前にWaylandソケットを待つことで、PyxelのEGL初期化失敗を起きにくくします。
- `Switch_to_PFE.sh` はPFE本体の `main.py` が数秒安定して動作した場合だけ、次回起動時のフロントエンドをPFEへ保存します。
- PFEからEmulationStationへ戻る場合は、PFEの `Settings > Quit > Switch to ES` を使います。

### 補足

既存の `PFE_demo` タグは、plumOSにPFEを導入済みのOSイメージ配布です。ROCKNIX向けPFE本体の公開リリースは、この `v1.0.2` から開始します。

## English

This is the first recommended PFE release for ROCKNIX.

### Download

Download `pfe-rocknix-v1.0.2-20260527.zip` from Assets.

Use this ZIP instead of GitHub's automatically generated `Source code.zip` / `Source code.tar.gz`. The ROCKNIX ZIP contains `pfe/` for `/roms/pfe` and `ports/` for `/roms/ports`.

### Installing on ROCKNIX

1. Copy `pfe/` from the ZIP to `/roms/pfe`
2. Copy the contents of `ports/` from the ZIP to `/roms/ports`
3. Run `01_install_pyxel.sh` from EmulationStation's Ports menu
4. Then run `02_install_pfe.sh`
5. To switch to PFE, run `Switch_to_PFE.sh`

For detailed instructions, see `pfe/docs/ROCKNIX_JP.md` inside the ZIP.

### Highlights

- ROCKNIX install scripts for PFE
- Pyxel 2.9.5 support
- RetroArch / Pyxel / standalone emulator launching
- PFE / EmulationStation switching
- Screenshot gallery
- Japanese text, themes, BGM, and gamepad configuration
- Favorites, recent games, search, and statistics

### Safety Notes

- `02_install_pfe.sh` installs and verifies PFE dependencies before registering the service.
- `02_install_pfe.sh` adjusts RetroArch screenshot settings and `menu_driver = "rgui"` for PFE.
- When `/roms/pfe` is on the second SD card, PFE waits for the PFE files and `/storage/roms` before startup.
- PFE waits for the Wayland socket before startup, reducing Pyxel EGL initialization failures.
- `Switch_to_PFE.sh` saves PFE as the next boot frontend only after confirming that `main.py` stays running for a few seconds.
- To return from PFE to EmulationStation, use `Settings > Quit > Switch to ES` in PFE.

### Note

The existing `PFE_demo` tag is for a plumOS image with PFE preinstalled. The public ROCKNIX PFE release line starts from this `v1.0.2` release.
